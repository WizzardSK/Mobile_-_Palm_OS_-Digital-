# Mobile - Palm OS (Digital)

Thumbnails for Palm OS games (No-Intro "Mobile - Palm OS (Digital)"), laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the No-Intro names up to the first bracket.

The snaps were taken with the Mu libretro core (Palm m515, Palm OS 4.1) in RetroArch: each game is launched on its own, run for 900 frames and the last frame is kept, cropped to the 160x160 screen and scaled 2x. Many games open with a shareware or license screen, which is what they show without a player. Games that need Palm OS 5 or a Tapwave Zodiac, or that stop with an error on the m515, have no snap.
